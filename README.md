# 🚗 Vehicle Rental Management System

A full-stack MERN application that allows users to browse, book, and manage vehicle rentals online. The project includes secure authentication, vehicle management, booking functionality, and an admin panel for managing the system.

---

## 📌 Features

### User Features
- User Registration & Login
- JWT Authentication
- Browse Available Vehicles
- Search & Filter Vehicles
- Book Vehicles
- View Booking History
- Responsive User Interface

### Admin Features
- Admin Login
- Add New Vehicles
- Update Vehicle Details
- Delete Vehicles
- Manage Bookings
- Manage Vehicle Availability

---

## 🛠 Tech Stack

### Frontend

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/vanshikasrivastava63/vehicle-rental-management.git
```

### Go to Project Folder

```bash
cd vehicle-rental-management
```

---

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

---

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```
